Thunderbird extension

Domain Mail Organizer

Configure customer rules separately for each work mailbox.

Safe by default

Previews never move messages or create folders. Setup and explicit Apply actions can create folders. An existing root or archive folder is used only when you approve that exact name below. After setup, automatic filing can recreate a missing configured customer child, but never an unapproved or missing customer root. When automatic filing moves a matched message, its customer email contacts are also added to the managed address book. If that book becomes unavailable, both automatic actions pause together. Starred messages remain protected by default.

Mail accounts

Each enabled account gets its own customer-folder tree; automatic moves never cross accounts.

Customer rules

Customers open collapsed and sorted by name. Expand a customer to edit its rules. Domain matching is exact: shutterfly.com does not match em.shutterfly.com. Add each domain or subdomain you want to match, and never enter a public suffix such as co.uk.

Processing defaults

Import existing customer folders

Choose folders and review their exact matching domains. Folders without a valid domain are added disabled and expanded for completion. Adding rules does not move mail, change folders, or approve the customer root. For a new setup, also approve the existing root in its account card and choose Save & set up folders.
